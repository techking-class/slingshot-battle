테크킹 운동회 새총 대전 - 노트북 서버 사용법
==========================================

[준비물]
- 노트북 1대 (윈도우 또는 맥)
- 학생 태블릿 최대 30대
- 노트북과 태블릿이 같은 와이파이에 연결되어 있어야 해요
- TV나 프로젝터 (선택)

[처음 한 번만: Node.js 설치]
1. https://nodejs.org 에 들어가서 LTS 버전을 내려받아 설치해요.
2. 다른 프로그램은 설치하지 않아도 돼요.

[수업 시간에 켜기]
1. 이 폴더를 노트북에 통째로 복사해요.
2. 윈도우: "start-windows.bat" 를 두 번 클릭해요.
   맥: "start-mac.command" 를 두 번 클릭해요.
   (맥에서 열리지 않으면 마우스 오른쪽 클릭 > 열기)
3. 검은 창에 접속 주소가 나와요. 예) http://192.168.0.15:3000
   - 학생 태블릿: 그 주소를 브라우저에 입력
   - TV 화면: 주소 뒤에 /tv 를 붙여서 열기
   - 선생님: 주소 뒤에 /host 를 붙여서 열기 (비밀번호 2580)
4. 윈도우에서 "방화벽 허용" 창이 뜨면 "허용"을 눌러 주세요.
   (허용하지 않으면 태블릿이 접속할 수 없어요)

[경기 진행]
1. 학생들이 이름을 쓰고 역할을 골라 입장해요. 팀은 자동으로 반반 나뉘어요.
2. 선생님 조작판에서 팀 섞기, 팀 바꾸기, 경기 시간(3/5/7분)을 정해요.
3. "경기 시작"을 누르면 시작해요. 30명이 안 되면 빈자리는 봇이 채워요.
4. 경기 중에도 일시정지, 다시 시작, 경기 끝내기를 할 수 있어요.
5. 경기가 끝나면 역할별 MVP가 모든 화면에 나와요. "대기실로"를 누르면 다음 판을 준비해요.

[알아두면 좋은 점]
- 경기 중에 늦게 들어온 학생은 봇 자리를 이어받아요.
- 태블릿 연결이 잠깐 끊겨도 15초 안에 다시 들어오면 같은 캐릭터로 이어서 해요.
- 15초 넘게 끊기면 그 자리는 봇이 맡아요.
- 관리자 페이지(/host) 비밀번호는 2580 이에요.
  바꾸고 싶으면 Render 의 Environment 에 PIN 을 추가하거나,
  노트북에서는  set PIN=1234 && node server.js  (맥: PIN=1234 node server.js)
- 포트를 바꾸고 싶으면: node server.js 4000
- 학교 와이파이가 기기끼리 연결을 막아 두는 경우(AP 격리)가 있어요.
  태블릿에서 접속이 안 되면 노트북 핫스팟이나 교실용 공유기를 써 보세요.

[인터넷 서버(Render)에 올리기]
- server.js, package.json, public 폴더를 GitHub 저장소에 올리고 Render 에서 Web Service 로 연결해요.
- Start Command: node server.js   / Region: Singapore 추천
- 관리자 페이지 비밀번호는 기본 2580 이에요. GitHub 저장소는 Private(비공개)로 만드세요.
- 무료 요금제는 15분 동안 아무도 접속하지 않으면 잠들어요. 수업 1~2분 전에 주소를 미리 열어 깨워 두세요.
